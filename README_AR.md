
# 📈 محلل فواتير البورصة المصرية

برنامج يقرأ صور فواتير حركة التداول بالذكاء الاصطناعي ويحسب:
- صافي الربح/الخسارة بعد العمولات لكل سهم ولكل عملية
- نسبة نمو/انكماش المحفظة والتدفق النقدي
- إجمالي العمولات المدفوعة ونسبتها من التداول
- مقارنة: الاحتفاظ بالسهم أفضل ولا البيع والشراء اليومي (مع حاسبة سعر التعادل)

## التشغيل

1. ثبّت Python 3.10 أو أحدث
2. افترمينال داخل مجلد المشروع ونفّذ:
   ```
   pip install -r requirements.txt
   ```
3. أنشئ ملف `.env`:
   - انسخ `.env.example` وسمّيه `.env`
   - ضع مفتاح API (من OpenAI أو Kimi/Moonshot)
4. شغّل:
   ```
   streamlit run app.py
   ```
5. افتح الرابط اللي هيظهر في المتصفح، ارفع صور فواتيرك، ودوس "اقرأ الفواتير"

## ملاحظات مهمة

- العمولة لو مش مكتوبة في الفاتورة بيحسبها تلقائياً بـ 0.285% — غيّر الرقم
  ده في `core/calculator.py` حسب نسبة شركتك الفعلية
- البيانات بتتخزن محلياً في ملف `borsa.db`
- الفواتير الأوضح (إضاءة جيدة، غير مائلة) تعطي دقة قراءة أعلى
